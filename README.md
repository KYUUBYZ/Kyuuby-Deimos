# Kyuuby-Deimos
A normal quadcopter drone's flight controller. this is only the V1, but in the future i will build a better one, becaus this one doesnt have the motor input and output.
It uses an STM32F405 as MCU, wit ha 8MHz crystal as OSC. It uses a SPI3 protocol to communicate with the SX1280 ( the radio module ) and SPI1 protocol for the BMI270, the IMU (Gyroscope and Accelerometer).
Its only purpose for now is to be a test to see if my design can works, so in the firmware there won't be anything difficult.

You will find a "detailed" (hope its detailed enough) guide in /Firmware.
